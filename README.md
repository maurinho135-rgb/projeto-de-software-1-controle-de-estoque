# projeto-de-software-1-controle-de-estoque
MVP web para cadastrar produtos, registrar entradas e saídas e consultar o saldo do estoque.
## Objetivo

Ajudar pequenos comércios a controlar o estoque sem recalcular o saldo manualmente.

## Escopo do MVP

- Cadastrar produtos com quantidade inicial.
- Registrar entradas e saídas e atualizar o saldo.
- Consultar o saldo e o histórico de movimentações.
- Bloquear saídas acima do saldo disponível.

## Tecnologias previstas

Python 3.12, Django 5.2 LTS e PostgreSQL.
